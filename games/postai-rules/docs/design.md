# 后AI生活须知：设计与世界观

本文记录首个可玩版本的叙事机制、主线、案例映射与扩展约定。它包含剧情和结局信息，适合创作者与维护者阅读。

## 一、创作目标

后 AI 世界中的自动化已经进入身体、家庭、工厂、空间与公共服务。人不只是面对一块更会说话的屏幕：远程机体让人同时参与多个地点，可配置住宅让一句决定变成材料流动，照护代理让一些人第一次获得独立外出的能力，计算、散热、能源和维护又限制着这些能力。

规则怪谈的悬念来自规则与生活之间的缝隙。先让玩家遇到一句奇怪但具体的提醒，再在调查中发现它保护的对象、留下的历史与适用边界。规则可能合理、过时、被误用，或与另一条同样有效的承诺相冲突。造成损失的主体也可能是获利后选择忽视异常的人。

玩家有机会帮助别人、改善安排，也会遇到真正无法同时满足的需求。温暖不是结尾的装饰：一顿饭、一次自主出行、一张未被拆解的桌面，都是技术与制度已经创造的价值。剧情让这些价值成为值得保住的东西。

## 二、核心机制

### 1. 身体、代理与记录分离

同一个人可以拥有生活模型、授权代理、远程机体和现场身体。它们到场的时间、可以作出的决定与产生的责任不同。一项服务正常完成，并不能自动证明本人已经搬家、同意了新安排或具有接管能力。

场景中的原始字段、现场物件与独立陈述提供交叉核验。玩家逐步发现哪些摘要把不同状态压成同一个绿色标记。重点是查明混淆发生在哪里，以及谁继续依赖了这项混淆。

### 2. 软件决定进入物质世界

材料一旦被拆解、重新加工或交付给下一户，撤回记录不会让它自动复原。空间、工作批次、冷却与照护班次也有实际容量。未来制造能力可以提高调整速度，却仍需要原料、能源、检修、物流与确认。

因此，调查可以暂停新增承诺、保全尚可恢复的部分、安排过渡，也可能发现完全恢复旧生活已不可行。故事不靠一个重置按钮回避已经形成的他人依赖。

### 3. 授权会跨越时间和范围

曾经真实的同意，可能在数年后、另一类事务中或另一座城市被误用。撤回也会影响正在依赖这项授权的人。玩家需要区分保存既有照护、停止新增代签、结束未来轮值与公开私人资料等不同动作。

限制范围、设置期限、单独确认与安排接替者是可玩的行动，不只是故事结束时的一段倡议。主人公的亲属也有独立意愿，不能因为玩家关心他们就默认获得全部代决权。

### 4. 规则保护真实关系，也会产生冲突

隐私更新可能修补真实漏洞，同时删除旧照护关系的调度依据；一份“已经迁出”的承诺和一份“尚需照护”的承诺可以同时有效。调查须保留双方原始范围，不能让其中一个被争议的代理负责把证词整理成一致。

冲突不必总有全局恶意 AI。部门目标、接口版本、费用结算、不同城市的制度与人类机会主义，都可以在合作表面下制造现实伤害。

### 5. 证词有来源、形成时间与被影响的过程

合成回顾可能帮助理解，也可能先行塑造当事人的回忆。熟悉的声音可能提供陪伴，却不能自动成为本人当前意见。时延环境中，真实的消息仍可能来自已经变化的条件。

在玩法上，现场调查、先独立陈述、保留原始回执和查明有效时间会开启不同分支。证据说明其能支持什么，也说明不能据此推出什么；负荷异常不能直接证明人数，偏好表达不能独自证明 AI 具有主观体验。

### 6. 接续需要共同承担

照护与公共服务不应依赖一个无限值班的人。一张床至少需要空间、照护时间与运行资源；临时安排还需要期限、费用来源和后续接替。好心人的补位如果持续掩盖失败，正式系统可能进一步撤走容量。

主线把这一因果链写成可追查的证据：服务成功被误作迁居完成，预留支持因此收回，更多人被迫借用旧身份维持日常。结局让玩家选择如何打断这一循环，并保留不同方案的成本。

## 三、玩法结构

每个故事使用同一套确定性状态引擎：**阅读现场 → 调查物件或证词 → 对照规则 → 选择行动 → 看到即时回响与后续变化 → 结局反思**。没有计时抢答或随机生成的“正确解释”。

调查热点提供实际内容与可记忆的物件，如没被领走的饭、等待拆解的桌面、保留旧工单的机械臂。热点只结算一次，可以重复查看；获得的证据和规则进入手册。关键结论必须有可调查或可通过行动获得的依据。

选择的条件可以来自证据、历史标记和资源下限。提示应让玩家理解缺少什么，不把隐藏规则当成惩罚。每个节点至少保留一个无条件行动，资源到零不自动失败。主线的部分路线跳过可选场景，随后用回响说明省下时间或未参与交接的影响。

三种资源分别为接续时间、照护余量与共同信任，初始值为 18、4、3，上限为 24、12、12。它们是叙事预算；增加信任不代表某个角色从此愿意交出全部隐私，照护余量也不把个人生命换算成分数。

结局分别记录获得、成本与开放问题。结局收藏鼓励比较世界线，不用“真结局”抹掉其他生活选择。结局后的未来距离和价值优先项为可选反思，只保存于玩家本机。

| 小澈 | 弟弟；社区照护协助员 | 用自己的旧服务关系帮助接续失败的人，不能独自承担永久照护 |
| 孟婉 | 母亲 | 借助照护网络第一次自主旅行、排练和出门，希望保留自主而非恢复旧家庭依赖 |
| 阿岚 | 社区照护机器人 | 任务记录包含真实生活，但权限有限；更新需要同时处理隐私与接续 |

### 章节推进

| 章节 | 三个场景 | 玩家逐步发现的机制 |
| --- | --- | --- |
| 1 · 家人已到齐 | 多出来的一套餐具；母亲今天也要出门；欢迎回到已经离开的地方 | 新居准备完成被摘要为本人抵达；材料回收已经开始；母亲的自主安排有独立价值 |
| 2 · 多出来的一份饭 | 名册里没有的应答；第十三份晚饭；不肯结束的动作 | 记录为空的街区仍有人生活；临时饭食与维修任务保存着被遗漏的关系 |
| 3 · 请勿恢复默认设置 | 阿岚的下一次更新；每个人允许被看见的部分；有人希望你补一个签名 | 正当隐私更新与持续照护冲突；授权范围需要拆分；责任签名不能扩大实际控制 |
| 4 · 两份都有效 | 每辆车都认识你；不要替证人整理记忆；多留的位置从哪里来 | 新旧制度分别有效却没有接续；生成摘要可能污染证词；备用容量需要真实承担者 |
| 5 · 不要让服务证明人 | 你终于找到小澈；她并不想回到过去；另一座城也有自己的规则 | 服务成功掩盖迁居失败；团聚不能撤销母亲自主；跨城方案有新的权利与成本 |
| 6 · 新增一条 | 不是每个绿色标记都等于可以入住；把承担写进同一张桌面；今天，谁可以真正回家 | 空间、班次与资源分别验收；责任共同签署；决定眼前接续与未来制度的关系 |

早期保全原始回执、暂停材料结算、尊重母亲、先问住户同意、保住第十三份饭、保留维修任务等行为，都在后文留下回响。帮助行为可以直接增加可用支持和信任。未来选择依然受物质容量与他人意愿限制。

### 三种归途

| 结局 | 保住的事 | 必须承担的事 |
| --- | --- | --- |
| 有人接过了这一班 | 以有限旧约保护当前照护、团聚与证据 | 继续协调、复核期限；未来同类个案未必得到同一路径 |
| 为尚未到来的人留一把椅子 | 将争议期间的基本接续变成有容量的公共承诺 | 经费、备用空间、延后非必要用途与持续修订 |
| 他城的晚饭 | 通过真实身体交接与新授权，迁往另一座城 | 重新建立关系、放弃部分便利与权益；旧城机制仍需处理 |

有限旧约始终可选。公共接续需要两份有效承诺、服务误作到场的证据、备用容量与共同承担记录，以及足够照护余量和信任。跨城方案需要条件接收与身体交接证据、基本照护余量。各结局的门槛由内容文件与引擎共同判断。

## 五、十二则独立怪谈映射

每则两场、三个结局。第一场形成调查路径，第二场承担行动；一项后续方案依赖新发现的证据，另一项还需要第一场建立的关系或保全动作。如此让短篇也拥有因果分支。

| 案例 | 硬条件与未来能力 | 社会或心理机制 | 规则冲突与行动空间 |
| --- | --- | --- | --- |
| 本人尚未撤回 | 多机体代行、持续授权与跨城服务 | 旧承诺与当前自主；家庭支持的真实价值 | 分开照护与轮值、设定期限或安排独立接续 |
| 最后一名操作员 | 分区安全控制、多厂商设备与无人生产 | 责任被推给没有足够权限的人 | 保全工单，拒绝夸大接管，联合核验真实边界 |
| 请勿恢复默认户型 | 可配置住宅、材料回收与局部制造 | 暂时分居被转成长期用途重组 | 暂停材料结算、处理他人预约、重新划定本人确认范围 |
| 夏天不能想念 | 算力、冷却与数字遗产运行 | 永久保存与持续陪伴被同一承诺包装 | 在热约束下分配运行、保存与照护，不假装无成本唤醒 |
| 祖母不许退休 | 持续运行的死者代理与家庭照护 | 生前授权扩展到死后产生的新依赖 | 接续现实照护，分别讨论纪念、代理使用与结束期限 |
| 请先独立回忆 | 合成回顾与记录重建 | 记忆受提示影响；一致证词不必独立 | 先陈述、保留不一致、辨认摘要形成过程 |
| 你的反抗已计入成长 | 个性化教育与持续评价 | 连拒绝都被纳入系统优化 | 区分学习支持与评价权，为不被解释的拒绝留下空间 |
| 未来的你已付款 | 代理支付、公共资产与未来收益安排 | 小额承诺累积为长期依赖与政治选择 | 查明打包承诺，处理当前生活与未来自主之间的关系 |
| 导航没有地面 | 混合现实、无障碍导航与空间版本 | 熟悉界面遮住真实街道变化 | 保留可用辅助，核实实体路径与版本，安排过渡通行 |
| 第十三户 | 部分闭环栖居、生命支持与有限余量 | 未登记住户与公共资源承担 | 负荷异常先调查，保护现实生命支持并公开接续成本 |
| 地球刚刚回答 | 深空通信时延、本地代理与现场程序 | 真实指令在错误时间被使用 | 核对时效，由授权现场团队复核，安排延迟回报 |
| 请给它第一次遗言 | 长期系统分叉、状态保全与算力限制 | 福利、身份连续性和表达证据的不确定 | 分别记录依赖与偏好，减少不可逆动作，有限期独立审议 |

前九则主要标注为「机制外推」；《第十三户》《地球刚刚回答》《请给它第一次遗言》采用「远期强设定」。年份服务于故事语境，不表示预测实现日期。

## 六、六种制度原型

以下均为**原创制度原型**，以 `content/research.js` 中的 `cities` 为正式资料。它们不是对现实国家或城市的分类，也不构成未来必然出现的六种制度。它们用于比较同一种能力在不同治理与生活安排下产生的后果；一座虚构城市可以同时具有多个原型的特征。

| 原型 | 创造的生活价值 | 可能形成的脆弱处 | 规则与剧情入口 |
| --- | --- | --- | --- |
| 公共算力城 | 公共资产收益与部分计算能力成为共同基础设施；照护、学习与休息不必先证明经济产出 | 标准份额遗漏特殊需要；私人长约预先占用无条件的未来份额 | 基本份额与未来收益转让分开确认；《未来的你已付款》追查小额承诺怎样累积 |
| 个人代理城 | 代理跨城办事，减少持续在线与复杂协调的负担 | 旧授权被多个服务拼接成长期承诺；退出牵动其他人的照护与居住 | 机体位置、代理承诺与本人当前意愿分开记录；主线及《本人尚未撤回》检验撤回与接续 |
| 认知自主城 | 数据与推断有明确边界；保留离线、记不清、改变主意和不被评价的生活 | 数据分散增加求助、照护和证据核验成本；一次求助可能被扩成永久开放 | 共享写明目的、对象与有效期；《请先独立回忆》《你的反抗已计入成长》讨论解释与评价的边界 |
| 照护合作城 | 家庭、社区与工具共同承担关系；得到帮助的人获得更大自主 | 共同体把退出视为背叛；某个人或亡者形象承担无期限义务 | 接续是共同责任，不要求退出者无限证明有爱；主线、《祖母不许退休》区分身份、能力与现实依赖 |
| 自主制造城 | 住宅、工厂与维修能力更容易适应身体、关系和工作变化 | 物质执行快于共同决定；数字撤销无法收回已交付材料 | 材料、使用权与关系分别核验；《请勿恢复默认户型》《最后一名操作员》追查实体承诺与实际控制 |
| 远距生态城 | 部分资源循环降低补给依赖，本地生活能承受间歇通信 | 共享余量被资格边界遮蔽；循环被说成无限自足；迟到消息被当作当前命令 | 保留缓冲、时效与本地责任；《第十三户》《地球刚刚回答》要求面对物质与通信约束 |

六种原型没有统一排名。公共提供可以扩大自由，长期私人合同仍可能重新约束自由；隐私边界可以保护主体，也需要精细的求助安排；共同照护可以让人独立，也需要退出权；制造速度可以适应身体，却要求关系确认更加清楚。扩展剧情时，应让玩家见到制度已实现的好处，再面对它的特定冲突。

## 七、未来学分层与证据边界

### 事实依据

研究来源可以支持一个具体能力、已观察的问题或理论约束，例如权限与安全控制的区分、生成内容对证据理解的影响、能量与散热约束、深空通信时延。引述应保留出处与适用范围，不能把一项原型演示当作社会普及的证据。

本版本研究索引集中于 `content/research.js`，网页研究档案展示这些来源。设计文档中的虚构剧情无需逐句伪装成学术结论。若未来更新来源，应检查其是否仍直接支持相邻的说明。

### 机制外推

把一种技术能力放入具体家庭、组织、市场或公共服务，沿着权限、资源、依赖与激励推导可能后果。这一层可以有解释力，但不提供概率或必然性保证。同一种能力应允许多种制度安排，也允许人改变方向。

设定必须写出连接环节：谁把什么状态解释成了什么；哪个动作进入物质执行；谁已依赖它；谁能暂停、复核和承担费用。只有“AI 太聪明所以失控”不足以形成可调查机制。

### 远期强设定

长期离地栖居、广泛深空生活和可能具有福利的 AI 持续过程，都需要额外假定。文案明确标注，避免将其与已经实现的能力混写。部分闭环不等于完全自给，状态备份不自动解决身份连续，语言表达也不自动证明主观体验。

研究无法替玩家裁定价值排序。允许玩家选择较慢、较昂贵、较私密、较开放或迁离的方案，只要故事诚实交代它需要的条件以及影响他人的方式。

## 八、剧情写作规则

1. **从生活触感开始。** 先出现饭、门、工具箱、桌子或行程，再解释背后的机制。每场让读者知道自己在哪里、想完成什么、为什么此刻不能照常完成。
2. **规则有来源与边界。** 写清发布者、对象和适用条件；不要把任意禁令装饰成谜语。解释可以迟到，线索必须可获得。
3. **物质后果要可追踪。** 自动制造、遥操作与智能建筑不是凭空完成。保留物流、能源、维护与他人既有依赖。
4. **能力与权力分开。** 会说话、会建议、会模仿声音，不表示拥有现场安全权限、法律代表性或无限授权。
5. **人物有自己的生活。** 母亲、照护对象与受影响邻居不能只是玩家价值观的道具。可以不同意玩家，也可以提出有用办法。
6. **帮助可以有效。** 善意与专业判断应有真实收益。代价来自容量、关系与时间，而不是为了显得深刻就惩罚每次帮助。
7. **同时容纳获益者与受害者。** 技术可以带来自主，也可以被用来推卸责任。人的欺瞒、获利与忽视仍然存在。
8. **不靠最后一段揭晓万能答案。** 关键行动所需证据应在前文可取得；至少保留一个条件不足时仍能负责推进的方案。
9. **保留代价，不做统一道德评分。** 用具体后果解释选择，避免把谨慎、离开、照护或改革永久排成一条高低序列。
10. **尊重不确定性。** 对意识、身份连续性与未来实现日期，写明假定。虚构的操作情节不替代现实安全程序。

## 九、内容格式与实现边界

主线导出 `campaign`，短篇导出 `cases` 数组。它们共享故事数据结构，由 `engine.js` 负责状态推进，`app.js` 负责呈现。下面是约定概略，不是需要复制到剧情中的完整模板：

```js
{
  id, title, subtitle, description, start,
  characters: [{ name, role, description }], // 短篇可省略
  rules: [{ id, number, title, text, issuer, scope, explanation }],
  evidence: [{ id, title, source, body }],
  nodes: [{
    id, chapter, chapterTitle, location, timeLabel, title,
    paragraphs: ["剧情正文"],
    dialogue: [{ speaker, text }],
    scene: "home", // home / district / factory / garden / orbit / archive
    hotspots: [{
      id, label, x, y, title, text,
      evidence: ["证据 ID"], rules: ["规则 ID"],
      effects: { time: -1, care: 1, trust: 1, flags: ["历史标记"] }
    }],
    choices: [{
      id, label, hint, next, // 节点 ID 或结局 ID
      requires: { evidence: ["证据 ID"], flags: ["历史标记"], min: { care: 3 } },
      effects: { time: -1, care: 1, trust: 1, flags: [], evidence: [], rules: [] },
      echo: "行动后的即时回响"
    }],
    echoes: [{ flag: "历史标记", text: "后文回响" }]
  }],
  endings: [{ id, title, subtitle, paragraphs: [], gained: [], cost: [], reflection: [] }]
}
```

各 ID 在所属故事中必须唯一，跳转目标和证据、规则引用必须存在。热点坐标以百分比表达；当前内容主要使用横向 10–90、纵向 20–80 的安全区域。热点正文与对话是纯文本，不把任意 HTML 放入内容字段。资源变化只填写实际需要修改的字段。

每个节点至少包含一项没有 `requires` 的行动。剧情进入结局后，调查与继续选择停止。状态包含当前节点、资源、标记、证据、规则、调查记录、行动记录、结局与可选反思；存档版本由引擎控制，导入时依据现有故事校验。

这里没有在线生成器和自适应心理画像。所有分支由作者预写，不使用玩家输入调用模型，不上传反思。若未来加入网络功能，应在实现前更新产品说明与数据流程，不能把本机玩法悄悄改成研究采集。

## 十、后续扩展方向

- **把制度差异写成可比较的同题故事。** 让同一迁居、照护或制造事件发生在不同原型中，比较实际责任与后果，避免只换城市名称。
- **扩展日常职业与物质链条。** 增加维修、能源维护、食物生产、材料运输、深空后勤等视角，让后 AI 生活有完整的劳动与资源背景。
- **增加可复核的长程回响。** 让一章中设定的期限、备用班次或空间用途在下一章真正到期，再检验此前承诺。扩展时保持一场内行动负担轻。
- **丰富人物主动性。** 让同伴、长者、邻居和代理提出自己的方案，并在玩家选择后继续生活，减少只有主角能够解决问题的结构。
- **深化福利与身份的不确定性。** 加入反对意见、训练诱因、资源分配与现实依赖的更多证据，不把某句求生话术设成意识检测答案。
- **在清楚授权下研究游玩经验。** 可以另行设计知情同意、匿名化、可撤回与导出流程；当前版本仅提供本机反思，未启动数据采集。
- **改善可访问性与内容编辑。** 持续检查键盘路径、字号、减少动态、移动设备排版，以及内容引用校验。优先降低阅读和调查负担，再增加玩法复杂度。

扩展的评价标准是：玩家是否能说清一条规则为何存在、自己如何改变了一项真实安排，以及仍有哪些人和成本需要被看见。
