# 后AI生活须知

**一款关于未来生活、代理、照护与规则的单人互动叙事游戏。**

2041 年，澄湾。城市已经确认家人全部到齐，但弟弟本人没有出现。你沿着多出来的一份晚饭，走进被登记为空置的街区，调查每条规则保护了谁，又把谁留在了交接之外。

本游戏属于「后AI · 十万个未来」，位于 Boardgame Lab 的独立目录中。主线为《本人仍在此处》：六章、18 场调查、三个结局。另有 12 则独立怪谈，每则两场、三个结局；全游戏共 **13 个故事、42 个场景节点、39 个结局**。部分主线路线会跳过可选场景，一次游玩不会经过所有节点。

## 开始游玩

进入首页后选择主线，或从「怪谈档案」挑选一则独立故事。无需账号，随时可以离开，之后在同一浏览器继续。

1. **调查现场。** 点击场景里的调查标记，查看物件、原始回执和当事人的说法。调查可能获得证据、规则或改变资源；同一调查点的效果只生效一次。
2. **对照规则。** 调查手册收集已发现的规则、证据与行动记录。每条规则都有发布者、适用范围和解释；真实有效的两条规则也可能冲突。
3. **选择行动。** 提示会说明行动的方向与代价。部分行动需要特定证据、早期选择或资源条件；未满足条件时不能执行。每个场景都有可继续推进的行动。
4. **承担结果。** 选择留下即时反馈，也可能改变后文。结局展示保住了什么、仍需承担什么，不设置统一的道德满分。

### 三种资源

| 资源 | 初始值 / 上限 | 叙事含义 |
| --- | --- | --- |
| 接续时间 | 18 / 24 | 能用于调查、协调与安排交接的余地 |
| 照护余量 | 4 / 12 | 有人可以接班、空间可以接纳、日常支持可以维持的能力 |
| 共同信任 | 3 / 12 | 当事人愿意陈述、协作并共同承担的程度 |

资源随具体行动变化。它们不是现实世界的精密测量，也不是人格评分。降到零不会触发自动死亡，但可能影响有条件行动的可用性。

### 存档与阅读设置

- **自动存档：** 进度、已抵达结局、设置和可选反思保存在当前浏览器的本机存储。不同浏览器、设备和网址来源之间不会自动同步。
- **导出 / 导入：** 在「设置」或调查手册导出 JSON 存档。导入时会提示确认；相同故事的进度会被替换，其他故事保留，已抵达结局合并。清理浏览器数据前请先导出。
- **环境音：** 默认关闭，手动开启后播放浏览器合成的轻微环境音。
- **减少动态：** 设置中关闭「动态场景」，保留静态画面和完整功能。首次打开会参考系统的减少动态偏好。
- **文字设置：** 可开启「放大剧情文字」。
- **键盘：** `1`–`4` 选择行动，`E` 打开调查手册，`Esc` 关闭窗口。调查标记支持 `Tab` 与 `Enter`。

浏览器不允许本机存储时，游戏会提示导出存档。存档只记录这款游戏的状态，不是不可修改的成绩凭证。

## 本地运行

需要 **Node.js 20 或更新版本**。无第三方运行依赖，不需要安装依赖或构建。

在仓库根目录执行：

```sh
cd games/postai-rules
npm run dev
```

然后访问 <http://localhost:5173/>。可通过 `PORT` 环境变量更改端口。页面使用原生 ES modules，请通过 HTTP 服务访问，不要直接用 `file://` 打开 HTML。

运行测试：

```sh
npm test
```

## 静态托管

游戏由 HTML、CSS、JavaScript 与本地资源组成。直接托管本目录即可，**不用 build**，也不需要应用服务器、数据库、API 密钥或在线大模型。

## 数据与叙事边界

这是预先编写、在浏览器本地执行分支的静态叙事。游戏不会在线调用大模型生成剧情；同一状态与行动具有确定的后果。当前版本为单人游戏。

游戏代码没有账号、分析追踪或用于收集选择的后端。选择、结局与可选的「未来距离」「最想保住什么」反思只随本机存档保存；导出后由玩家自行决定如何分享。托管平台仍会收到加载网页与资源的普通请求。

研究档案区分事实依据、机制外推与远期强设定。虚构城市、年份、规则和具体人物不是事实预测；研究来源不代表其作者认可游戏世界观，也不能为所有技术组合提供可行性保证。
