# 版本和使用入口

这是一套面向工作坊与多人试玩的未来社会合作叙事桌游。从2031年出发，沿着2036、2042、2049、2057、2066六个条件情景年代，经历城市建设与普通人的未来生活。年代不等于技术实现时间表；技术边界、扩散速度和城市制度共同决定生活能否发生。

**主要机制：共同建造城市的能力，独立选择一段人生，并在下一轮收到选择回声。** 2–4人合作，六轮；每人每轮两次城市行动。当前正式试玩版为满画幅 v1.2（未经过真人平衡测试）。

## 典型的故事体验

- 2031：社区工坊开始制造另一间工坊的骨架；有人争取工坊，也有人更需要公共维修队。
- 2036：你可以把海浪穿在身上，与朋友创造一种新的共同感官语言。
- 2042：借用冰下机器人的身体，探索自己从未到达过的蓝色空间。
- 2049：家和地址可以分开；一个街区慢慢搬迁，关系却未必跟着搬走。
- 2057：你在轨道站尝试失重舞蹈，家人的晚餐也可能横跨地月。
- 2066：你参与制造下一座工厂和下一座城市，回看自己曾经承诺过的未来。
