# Workshop现场试玩与主持导览

## 两分钟开场

《十万个未来》邀请大家先生活在未来，再讨论现实中怎样让这些未来出现。你们并不扮演宏观规划者，而是具体的居民：有人想有新的身体，有人想留下一间工坊，有人只希望与家人共享一个周末。技术、制度和城市建设改变这些愿望的可实现条件。

今天大家共同生活在同一座未来城市，经历2031、2036、2042、2049、2057、2066六轮。每人有自己的身份和愿景，全桌共享一座城市。没有唯一正确的未来，重点是尝试，协商，承担后果。

## 推荐活动进程

| 时间 | 活动 |
|---|---|
| 0–7分钟 | 播放《明日编年》女声精修版，6分57秒 |
| 7–15分钟 | 分桌、选城市、抽居民和愿景、发放起始筹码 |
| 15–30分钟 | 主持人带大家完成2031首轮 |
| 30–105分钟 | 各桌独立推进2036—2066 |
| 105–120分钟 | 共同结局、个人叙述、对现实行动的讨论 |

时长供组织者调整；整局实际时长尚未通过真人桌测确认。

## 开局清单

- [ ] 每桌2–4人，棋盘2张A4接成A3；角色、愿景与城市牌放好。
- [ ] 城市按所选城市牌设置四轨；承压=2；每人预算=4、体验=0。
- [ ] 人生牌按年代分六堆；工程牌和时代牌按编号；出资筹码、玩家板及故事册到位。
- [ ] 每人第一轮照常预算+3；第1轮没有旧回声；执行E01，公开P01–P03。
- [ ] 每人看2张本年代人生牌，留1张。完成“第一圈行动→选生活→第二圈行动”。

## 主持人只需记住的五件事

1. 每人每轮两次城市行动，分在生活选择前后。
2. A需满足能力门槛并付费；B没有能力门槛但仍按牌付费；C免费且预算+1。
3. 投资时先扣预算再放筹码；工程资金目标=人数×2，满足能力要求才建成。
4. 回声来自上轮自己选择的那条分支；第六轮当轮结。
5. 不淘汰玩家。终局先看共同城市，再看每个人愿景与经历。

## 活动收束讨论

- 哪一种未来生活，你在今天会主动争取？
- 它依赖的最稀缺条件究竟是技术、能源、制造、组织还是制度？
- 如果现实中现在就能动手建一个前置条件，你愿意和谁共同完成？
